# Кабинет учебной группы ПОНБ-УП-304С

Официальный учебный веб-портал и электронный кабинет для студентов группы **ПОНБ-УП-304С** специальности «Правовое обеспечение национальной безопасности» (уголовно-правовая специализация) **Института права Уфимского университета науки и технологий** (г. Уфа).

- **Опубликованный сайт на GitHub Pages:** [https://luwili.github.io/ponb-up-304s-cabinet/](https://luwili.github.io/ponb-up-304s-cabinet/)
- **Репозиторий проекта:** [https://github.com/luwili/ponb-up-304s-cabinet](https://github.com/luwili/ponb-up-304s-cabinet)
- **Город и часовой пояс:** г. Уфа, Республика Башкортостан (`Asia/Yekaterinburg`, UTC+5)
- **Куратор группы:** ст. преподаватель кафедры уголовного права и процесса Нурмухаметов Руслан Наилевич

---

## 🌟 Разделы кабинета

1. **Главная (Информационная панель)**:
   - Индикатор текущего времени Уфы (`Asia/Yekaterinburg`, UTC+5).
   - Динамический статус учебной пары («Идет 3 пара», «Большая перемена», «Занятия завершены»).
   - Расписание на сегодня с аудиториями и преподавателями.
   - Срочные учебные дедлайны и закрепленные объявления куратора.
   - Панель быстрого перехода по всем разделам сайта.

2. **Расписание занятий**:
   - Точное подтвержденное расписание группы ПОНБ-УП-304С на 8-ю учебную неделю (19–24 октября 2026 г.).
   - Режимы отображения: **«День»** и **«Вся неделя»**.
   - Номера пар, время занятий, форма (Практика / Лекция), аудитории (ул. Достоевского, 131) и преподаватели.
   - Справочная таблица официального звонкового расписания Института права.

3. **Предметы**:
   - Полный каталог всех 10 дисциплин 5-го семестра (Уголовный процесс, Уголовное право, Финансовое право, Гражданский процесс, Административный судебный процесс, Гражданское право ч.2, Экологическое право, Спецподготовка, Финграмотность, ОФП).
   - Фильтры по форме итогового контроля (Экзамен / Зачёт / Диф. зачёт).
   - Развернутые карточки дисциплин с прикрепленными темами, задачами и преподавателями.

4. **Темы и конспекты**:
   - Удобный ридер лекционных и семинарских материалов.
   - Переключение между режимами: **«Полный конспект»** (подробная правовая доктрина со ссылками на законы) и **«Краткий для записи»** (шпаргалка/тезисы для семинара).
   - Интерактивное оглавление со ссылками-якорями.
   - Регулировка размера шрифта (масштабирование), копирование текста, скачивание Markdown и режим чистой печати (`Ctrl+P` без лишних кнопок).
   - Статус верификации по актуальному законодательству РФ.

5. **Задачи и практикум (Кейсы)**:
   - Структурированные правовые задачи с фабулой дел, вопросами, нормативной базой (УК, УПК, КАС РФ, Постановления Пленума ВС РФ).
   - Краткий ответ для ответа на семинаре.
   - Интерактивная кнопка-спойлер «Показать подробное правовое решение».

6. **Задания и дедлайны**:
   - Трекер практических заданий и процессуальных актов с дедлайнами и приоритетом.
   - Личные чекбоксы «Выполнено» с сохранением статуса в браузере.
   - Прикрепленные методические материалы и бланки документов.

7. **Подготовка к экзаменам (Флеш-карты)**:
   - Интерактивный режим двусторонних карточек «вопрос → ответ» с плавной 3D-анимацией переворота.
   - Кнопки самопроверки «Знаю» и «Повторить позже».
   - Счетчик прогресса усвоения вопросов и режим перемешивания (Shuffle).
   - Альтернативный режим полного перечня экзаменационных вопросов.

8. **Справочник преподавателей**:
   - **186 проверенных преподавателей института**, собранных напрямую с официального сайта `law-bsu.ru`.
   - Вкладка **«Преподаватели нашей группы (11)»** с указанием конкретных дисциплин.
   - Поиск по ФИО, фильтр по кафедре, ученым степеням (д.ю.н., к.ю.н.) и ученым званиям (профессор, доцент).
   - Прямые ссылки на официальные страницы кафедр `law-bsu.ru`.

9. **Кафедры Института права**:
   - Все 8 кафедр с адресами, номерами кабинетов, официальными телефонами, email и списком преподавателей.

10. **Наша группа (ПОНБ-УП-304С)**:
    - Сведения о кураторе, специальности, специализации и форме обучения.
    - **Политика конфиденциальности (`publishRoster: false`):** персональные данные студентов (ФИО, ISU ID, номера зачеток) исключены из публичной сборки.
    - Встроенный клиентский инструмент для локального безопасного просмотра `private-data/roster.json` в браузере владельца без выгрузки в сеть.

11. **Институт права и полезные ссылки**:
    - Подтвержденные адреса корпусов (ул. Достоевского 131 и ул. Заки Валиди 32).
    - Официальные ссылки: расписание, заказ справок, практика, студенческий совет, дирекция, СПС КонсультантПлюс, Гарант, Pravo.gov.ru.

12. **Избранное**:
    - Быстрый доступ к сохраненным темам и задачам с мгновенным удалением.

13. **Глобальный поиск (`Ctrl+K`)**:
    - Мгновенный поиск по конспектам, статьям законов, задачам, преподавателям и кафедрам с поддержкой русского регистра и букв «е»/«ё».

## 🚀 Быстрый старт и локальный запуск

### 1. Установка зависимостей
Требуется Node.js 18+ (рекомендуется Node 20 или 24).
```bash
npm install
```

### 2. Запуск локального сервера разработки
```bash
npm run dev
```
Откройте в браузере адрес `http://localhost:5173`.

### 3. Проверка типов и сборка
```bash
npm run check
npm run build
```
Готовая статическая сборка будет находиться в директории `dist/`.

## 📁 Подключение будущей папки с материалами (`CONTENT_PATH`)

Если вы подготовили локальную папку с файлами и хотите импортировать их в проект:

```bash
# Для Linux / macOS:
CONTENT_PATH="/абсолютный/путь/к/материалам" npm run content:import

# Для Windows (PowerShell):
$env:CONTENT_PATH="C:\materials"; npm run content:import
```

Команда импорта:
1. Сканирует указанную папку на наличие `.md`, `.txt`, `.pdf`, `.docx` файлов.
2. Проверяет структуру и формирует `src/data/imported-content.json`.
3. Создает подробный отчет `import_report.json` со списком добавленных файлов и предупреждений.
4. **Не изменяет** ваши исходные файлы.

Пример рекомендуемой структуры папки с материалами приведен в каталоге `materials-example/`.

## 🔒 Защита персональных данных студентов (`ROSTER_PATH`)

В соответствии с правилами публикации на открытых хостингах:
1. Файл со списком группы хранится в локальной папке `private-data/roster.json` или `private-data/Список группы.md`.
2. Папка `private-data/` и файлы `*roster*` добавлены в `.gitignore` и **никогда не попадают в репозиторий Git и в публичный бандл**.
3. На сайте включен режим `publishRoster: false`. Студенты или владелец могут просматривать список локально через встроенную кнопку загрузки в разделе «Наша группа» (обработка происходит только внутри браузера).

## 🔄 Обновление справочника преподавателей с сайта law-bsu.ru

Для повторной автоматической синхронизации данных профессорско-преподавательского состава:
```bash
npm run institute:sync
```
Скрипт последовательно обращается к официальным разделам кафедр на `law-bsu.ru`, извлекает актуальный состав, ученые степени, звания, награды и обновляет файлы:
- `src/data/teachers.json`
- `src/data/departments.json`

## 🌐 Автоматическая публикация на GitHub Pages

Публикация настроена через GitHub Actions:
`.github/workflows/deploy.yml`

При любом обновлении и отправке изменений в ветку `main`:
```bash
git add .
git commit -m "Обновить учебные материалы"
git push origin main
```
GitHub Actions автоматически:
1. Установит зависимости через `npm ci`.
2. Проверит TypeScript-типы (`npm run check`).
3. Соберет оптимизированный бандл (`npm run build`).
4. Опубликует сайт на **GitHub Pages**: [https://luwili.github.io/ponb-up-304s-cabinet/](https://luwili.github.io/ponb-up-304s-cabinet/)

Статус сборки и логи можно отслеживать во вкладке **Actions** вашего репозитория:
[https://github.com/luwili/ponb-up-304s-cabinet/actions](https://github.com/luwili/ponb-up-304s-cabinet/actions)
